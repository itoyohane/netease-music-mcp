# 功能需求与验收

服务通过本地 stdio 提供 11 个 MCP 工具。客户端负责自然语言交互、展示二维码和撰写总结，服务负责返回数据、维护会话及写入文件。

| 用户需求 | 可观察的验收条件 |
| --- | --- |
| 搜索指定录音版本 | 未登录时可按关键字搜索，候选带 ID、歌手和专辑，下载时传入选定 ID。 |
| 登录后跨聊天使用 | 扫码区分等待扫码、等待确认、过期和成功。成功后重启服务仍可读取会话。退出后账号功能要求重新登录。Windows 可在独立浏览器中登录。 |
| 获取当天日推 | 返回歌曲列表、获取时间和北京时间日期。登录失败应报告错误。 |
| 了解收藏和创建的歌单 | 列表区分是否为本人创建。详情支持分页，返回曲目数、本页时长和歌手出现次数。客户端读完所需页后汇总，说明不可访问的部分。 |
| 下载指定歌曲到文件夹 | 接受绝对目录，支持 standard、exhigh、lossless、hires 四档请求。常规接口失败时默认尝试 DownList 播放接口方式；可设置 playback_fallback=false 关闭。返回实际格式、路径、source 和原始接口失败原因。两个接口均失败时报告具体错误，已有同名文件不覆盖。 |
| 转换本地 NCM | 接受单个 NCM 的绝对路径，调用 ncmdump，在目标目录保存源编码的 MP3 或 FLAC。依赖缺失、格式不支持或文件名冲突时给出错误，保留原文件。 |

## 运行约束

- 需要 Node.js 22+。联网功能依赖网易云接口、账号权限和曲目可用性。浏览器登录依赖 Windows 上受支持路径中的 Edge 或 Chrome。
- 单曲下载上限为 512 MiB。有大小或 MD5 信息时校验服务端提供的值。客户端按返回的实际格式决定是否调用 NCM 转换。
- 播放回退独立实现 [DownList](https://github.com/xxxkjing/DownList/blob/main/main.py) 的桌面 eapi 取链方式，不运行其 GUI 或导入其 Python 代码。只向网易云发送会话；拒绝试听标记、错误曲目 ID、缺失时长以及与原曲相差超过 2 秒的响应。额度和曲目可用性仍以网易云实际响应为准。
- 会话和临时浏览器配置保存在本机，工具响应不包含登录 Cookie。发布物只包含源码、测试、依赖清单和文档。
- 离线测试覆盖工具发现、参数验证、分页、扫码请求、权限错误、下载完整性及文件冲突。端到端验收另需用户实际扫码、一首账号可下载的歌曲，以及可读的 NCM 样本和 ncmdump。
